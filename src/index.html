Exile Build Advisor

Path of Exile 2 · build check-up

See what's holding your character back

Path of Building, a free program, turns your character into a long code. Copy that code and paste it below. The advisor reads your gear, skills and passive tree and shows where you stand. Everything runs in this page; nothing is uploaded.

You don't need to know this code. It is not a password. Path of Building makes it for you from your character, and you copy it from there.

Get your build code

        
Path of Building is a free program that copies your character from the game. You need the version for Path of Exile 2.

        
    
          
  1. Install Path of Building for Path of Exile 2. Download it from pathofbuilding.community (choose the PoE 2 version). It is a different program from the one for the first game.
    2. 
          
  2. Start a build. Open the program and click New. Then click Import/Export Build in the top-left corner. The build list starts empty: you do not need a build from anyone, because the next steps make one from your own character.
    3. 
          
  3. Sign in once. Sign in at pathofexile.com (not pathofexile2.com) in your browser first. Its sign-in page shows Path of Exile 1 pictures; that is right, because both games share one account. Then, under Character Import, click Authorize with Path of Exile and approve the request in your browser within 30 seconds (PoB counts down). Afterwards PoB shows Logout from Path of Exile API, which means you are signed in.
    4. 
          
  4. Choose your character. If PoB shows select your character's realm and a Start button, click Start first. Then pick the League (for example Standard) and then your character from the list below it.
    5. 
          
  5. Import everything. Click Passive Tree and Jewels, then Items and Skills. Leave Delete jewels, Delete skills and Delete equipment ticked so old data is replaced. Leave Ignore weapon swap unticked so your second weapon set is included. The status line turns green.
    6. 
          
  6. Make the code. Only after importing: under Build Sharing, click Generate, then Copy. A code already in the box before you import is an empty build. Use the code itself, not Share: Share makes a website link, and this page cannot open those.
    7. 
          
  7. Paste it here and click Read my build. Repeat steps 4 to 7 whenever your character changes.
    8. 
        

        
        

          Something went wrong?
          
    
            
  • The character list is empty: check the League box. Characters in an event league only show when that league is chosen.
    • 
            
  • "Could not decompress the code": the code was cut off. Click Copy again and paste the whole thing.
    • 
            
  • The code is very long: that is normal. Codes are often 10,000 characters or more.
    • 
            
  • The account lookup did not work: that is common. It needs a public profile and a character poe.ninja has picked up. Use the build code instead.
    • 
            
  • The page says the passive tree is a different version: open Game data at the top right and refresh it.
    • 
          

        

      

    

  


  
  

    
    

      
Tutorial · about 10 minutes

      
How to use the advisor

      
New to Path of Exile 2 or to build tools? Start here. This walks you from "I have a character" to "I know what to fix next", one step at a time. You can try every step with the example build.

1What it does

          
The advisor reads your character (gear, skills and passive tree) and points out what is holding it back: resistances that are too low, gems and passives that do nothing, mana that runs out, and more. For each problem it says why it matters, what fixing it gains, what it costs and what to do, and it puts the best-value fixes first.

          
Everything happens inside this page on your computer. Nothing is uploaded, and there is no account to make.

        


        

          
2What you need

          
    
            
  • A Path of Exile 2 character, at any level. You do not need a build file from anyone else: Path of Building makes one from your character.
    • 
            
  • Path of Building for Path of Exile 2, a free program that copies your character from the game. Get it from pathofbuilding.community and choose the PoE 2 version. Players call it "PoB".
    • 
            
  • Optional: a build guide you follow (for example from maxroll.gg) and a rough idea of prices on the trade site.
    • 
          

          
Tip: no PoB yet? Click Open the example build above to see everything first, then come back.

        


        

          
3Get your build in

          
There are three ways. The first one always works.

          
First time with Path of Building? : it covers installing, signing in and copying the code, with a check after every step.

          
A. Paste a build code from Path of Building (recommended)

          
    
            
  1. Open PoB, click New, then Import/Export Build. An empty build list is normal.
    2. 
            
  2. Sign in once. Sign in at pathofexile.com in your browser first, then click Authorize with Path of Exile and approve in the browser within 30 seconds. Afterwards PoB shows Logout from Path of Exile API.
    3. 
            
  3. Pick your league and character, then click Passive Tree and Jewels and Items and Skills.
    4. 
            
  4. Optional but useful: in PoB's Skills tab, set your main attack or spell as the Main Skill. Then the advisor can talk about damage and mana for that skill.
    5. 
            
  5. Under Build Sharing click Generate, then Copy. Not Share: that makes a web link the advisor cannot open.
    6. 
            
  6. Paste into "Your build code" on the start screen and click Read my build.
    7. 
          

          
B. Open a saved file

          
Click Open a saved file to load a build you saved in Path of Building (an .xml file in the Builds folder in Documents), or a text file with a code in it. The Builds folder stays empty until you click Save in PoB; you don't need it for method A.

          
C. Look up by account name

          
Type your account name (like Name#1234), character name and league. This asks the website poe.ninja for your character. It often does not work: poe.ninja only knows characters with a public profile that it has picked up, and it does not let other web pages read its data unless you set up a small proxy (see Advanced in that box). If it fails, the page tells you why. Use method A.

          
Several versions in one code? Some codes hold more than one passive tree, skill set or item set. Pickers appear in the banner at the top so you can choose which one to review.

        


        

          
4Read the check-up

          
After your build loads, the Check-up tab opens. Each problem is a card like this one (from the example build):

          

            
#1Fix nowResistances
              

            
Cold resistance is 21%, 54 below the cap

            

              
Why
Below the 75% cap you take more cold damage than you need to.

              
What it gains
Capping it means about 68% less cold damage taken.

              
Cost
≈ 10 exalted · a short trade or task

              
What to do
  • Find +54% Cold Resistance in total on gear.
Search: Helmet with 30%+ cold resistance ↗

            

          

          

            
#1
Its place in the ranking. Lower numbers give you the most for the least.

            
Fix now Worth doing Tip
How serious it is. Start with "Fix now".

            
How much it helps what you care about, compared with the other cards.

            
probably check this
"Probably" means very likely. "Check this" means the page cannot be sure: look in the game or in PoB before acting.

            
unknown
The page never guesses. When something cannot be worked out from your build or the game data, it says unknown.

          

          
Use the area buttons (Resistances, Skills, Gear…) to filter, and Most serious first if you prefer that order. Areas with no problems are listed at the bottom in green.

          
The other tabs describe your character: Overview (resistances and key numbers), Skills (each skill, its supports, cost and Spirit), Gear and Passive tree. Tap any ? for a short explanation.

        


        

          
5Tell it what you want

          
What matters to you

          
At the top of the check-up, rate Damage, Survivability, Mana, Ease of play and Progression from Not to Most. The ranking changes straight away. Dying a lot? Set Survivability to Most.

          
Your details tab

          
    
            
  • League: Standard, or the event league's name. Trade links search this league.
    • 
            
  • Budget and spare currency (one per line, like 12 exalted): cards then say "over your budget" or "your spare currency covers it".
    • 
            
  • Items in your stash: in the game, hover an item and press Ctrl+C, then paste here. If one of them fixes a problem, the card says "In your stash".
    • 
            
  • Prices: prices change every day, so you enter them. Look up a few items on the trade site and type the price in Exalted Orbs. Blank means unknown, and the cost then shows "price unknown".
    • 
          

          
All of this is saved in your browser only.

        


        

          
6Act on a fix

          
Buying an item

          
    
            
  1. Click a brass Search button on a card. The official trade site opens with the filters filled in (it may ask you to sign in).
    2. 
            
  2. The text beside the button says which item it replaces and what it keeps. Add any other stats you want on the trade site.
    3. 
            
  3. Buy it. For "Instant Buyout" listings, click Secure Item on the site; the game takes you to the seller's hideout, where you buy it from their merchant. This needs the asynchronous trade feature, unlocked in Act 4 at Kingsmarch. For other listings, message the seller in the game.
    4. 
            
  4. Equip it, then make a new code in PoB and read it again to see the difference.
    5. 
          

          
Other kinds of fix

          
    
            
  • Supports that do nothing: open the skill gems panel in the game and move the support to a skill it helps. Free.
    • 
            
  • Gem level too low: use an Uncut Skill Gem (or Uncut Spirit Gem for always-on skills) of the level shown.
    • 
            
  • Passives doing nothing: refunding costs gold. Right-click the passive on the tree to refund it, then spend the point elsewhere.
    • 
            
  • Crafting: cards suggest a simple route when there is one, such as an Essence that guarantees a resistance on a magic item.
    • 
          

          
Work in small steps. Fix one or two cards, make a new code, read it again. The list updates and the next best fix moves to the top.

        


        

          
7Compare with a guide

          
Following a build guide? Open the Guide tab.

          
    
            
  1. Best: on the guide page, find its Path of Building button for the stage nearest your level and paste that code. The advisor then compares skills, supports, passives and unique items exactly.
    2. 
            
  2. Also useful: press Ctrl+A then Ctrl+C on the guide page and paste the text. The advisor reads the "last updated" date, the patch, the ascendancy order and the stat priorities.
    3. 
            
  3. Click Compare.
    4. 
          

          
If the guide was written for an older patch than the current one, a red box warns you. Guides go out of date, so always check the date. "Guide only" items are what the guide uses and you do not; "yours only" are things you use that the guide does not.

        


        

          
8Keep it up to date

          
    
            
  • Your character changed? Repeat the PoB steps and paste the new code. The page remembers your last code, goals and details.
    • 
            
  • The game had a patch? Click Game data at the top right and then Refresh game data. It downloads the latest gem and passive data (about 6.5 MB) and keeps it in your browser.
    • 
            
  • Guide tab: update the "Current game patch" box when a new patch comes out.
    • 
          

        


        

          
9Words you will meet

          

            
Resistance
Cuts damage of one element (fire, cold, lightning, chaos). Capped at 75%. Low resistances are the most common reason new characters die.

            
Life / Energy shield
Your health, and a recharging shield on top of it.

            
Mana
Pays for skills. If it runs out, you cannot use them.

            
Spirit
A budget for skills that stay switched on (buffs, auras, minions). You cannot reserve more than you have.

            
Skill gem / support gem
Skill gems give you abilities. Support gems are added to a skill to change it, and usually make it cost more.

            
Meta gem
A gem that holds other skills and uses them for you, like "Cast on Critical".

            
Passive tree / notable / keystone
The big tree of bonuses you spend points on. Notables are larger named nodes; keystones change the rules.

            
Ascendancy
Your specialisation, earned in the Trials. Its points are very strong.

            
Mod
One line of stats on an item, like "+30% to Fire Resistance".

            
Rare / unique
Rare (yellow) items have random mods. Unique (orange) items have fixed, special mods.

            
Exalted / Divine Orb
Common trading currencies. The advisor prices everything in Exalted Orbs.

            
Uncut gem
An item that becomes a new gem or levels one up, at the level written on it.

            
Essence
Crafting currency that turns a magic item into a rare one with a guaranteed mod.

            
League
Standard lasts forever; event leagues start fresh. Trade happens within a league.

            
PoB
Path of Building, the free program that copies your character.

          

        


        

          
10Questions

          
I don't have a build to load.
You don't need one from anyone. Path of Building makes the build from your own character when you import it (section 3). A guide's build is only needed for the optional Guide tab, to compare with yours.

          
The page says "unknown" a lot.
That is on purpose. Damage is unknown until you set a Main Skill in PoB; costs are unknown until you enter prices. The page would rather say unknown than guess.

          
Spirit says "over budget", but my skills all work in the game.
Then Path of Building is missing a Spirit source, often a setting in its Configuration tab. That card is marked "check this" for that reason; you can ignore it.

          
A card says a passive or mod does nothing, but I think it does.
Cards marked "probably" can be wrong when your build converts damage or swaps skills in. Cards without a mark come straight from the game data. If in doubt, check the mod's wording in the game.

          
A trade link opens an empty search.
The text beside each button lists the filters, so you can set them by hand. Make sure your league is right in Your details.

          
Is my data safe?
Nothing leaves your computer except when you click a trade link, refresh game data (downloads from GitHub) or use the account lookup (asks poe.ninja). Everything you type is stored only in this browser.

          
Can I share the advisor?
Yes, for non-commercial personal use: send the file as it is. See About and licence at the bottom of the page.
