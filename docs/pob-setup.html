Exile Build Advisor · setup sheet

Get your build code from Path of Building

Path of Building (PoB) is a free program that copies your Path of Exile 2 character. The advisor reads the code it makes. Follow these steps in order and check each "You should see" line before moving on. You do not need a build from anyone else: PoB makes one from your own character.

Windows PCAbout 10 minutes the first timeAbout 1 minute after thatChecked against PoB v0.23.1

Install

once

  1. Download Path of Building for Path of Exile 2.

    Download the installer (about 340 MB)

    This is the official link from pathofbuilding.community. Make sure it says PoE2: the program for the first game will not work.

    a file called PathOfBuildingCommunity-PoE2-Setup.exe in your Downloads folder.

  2. Run the file and click through the installer with the default choices.

    If Windows shows Windows protected your PC, click More info, then Run anyway. Only do this for the file from the link above.

    Path of Building opens on a list of builds, with a New button at the top. If it offers an update first, let it update.

Sign in

once; PoB remembers you

  1. Click New, then Import/Export Build in the top-left corner.

    The build list starts empty, and that is normal. You do not need a build file from anyone: the next steps make one from your own character.

    a box called Character Import with the status Not authenticated and a button Authorize with Path of Exile.

  2. Open your default web browser and sign in at pathofexile.com first. Finish signing in completely, including Steam or other sign-in options.

    PoB opens your default browser. If you sign in with a different browser, PoB's page will ask you to sign in again and the 30 seconds run out.

    Doing this now makes the next step quick. Use pathofexile.com, not pathofexile2.com: that is where PoB asks for approval.

    The sign-in page shows Path of Exile 1 pictures. That is correct. Both games share one account and one sign-in page. PoB still imports your Path of Exile 2 characters: its realm box says PoE2.

  3. Back in PoB, click Authorize with Path of Exile. Your browser opens a Path of Exile page: approve the request.

    You have 30 seconds. PoB shows Logging in... (30) and counts down. That is too short to sign in through Steam, which is why step 4 comes first. If it runs out, or the browser says localhost refused to connect, nothing is broken: click the button again and approve straight away.

    the browser says PoB 2 - Authentication Successful. Back in PoB, the status changes to Character list successfully retrieved. and a Logout from Path of Exile API button appears.

    Already signed in from before? Then PoB skips this and shows Authenticated with select your character's realm:, a PoE2 box and a Start button. Leave it on PoE2 and click Start.

Make the code

every time your character changes

  1. If you see a Start button, click it first. Then, under Choose character to import data from, pick your League, then your character.

    Characters only appear under their own league. Event-league characters are not under Standard.

  2. Click Passive Tree and Jewels. If a box asks to overwrite the current tree, click Import.

    Passive tree and jewels successfully imported.

  3. Click Items and Skills. Leave the tick boxes as they are.

    The defaults are right: Delete jewels, Delete skills and Delete equipment ticked; Ignore weapon swap unticked.

    Items and skills successfully imported.

  4. Under Build Sharing, click Generate, then Copy.

    Only after steps 7 and 8. The Code box can already hold a code before you import, but that code is for an empty build. Always click Generate again after importing.

    Do not use Share. It makes a web link, and the advisor needs the code itself.

    a long line of letters and numbers in the box. It is often thousands of characters long; that is normal.

  5. Open poe2-advisor.html, paste into Your build code and click Read my build.

    your character's name and class at the top, and the Check-up list below it.

If something goes wrong

What you seeWhat to do
The countdown reached 0 and it says Not authenticatedSign in at pathofexile.com in your browser first, then click Authorize with Path of Exile again and approve within 30 seconds.
The sign-in page looks like Path of Exile 1, so it seems to be the wrong gameIt is the right page. Path of Exile 1 and 2 use the same account and sign-in on pathofexile.com. Sign in and approve; PoB then lists your PoE 2 characters. You do not need to start again.
After approving, the browser says This site can't be reached / localhost refused to connectApproval took longer than 30 seconds (often because you had to sign in, for example through Steam), so PoB stopped waiting. You are signed in now: click Authorize with Path of Exile again and approve immediately. Make sure it opens the same browser you signed in with.
The browser page never openedOpen your browser yourself, then click the button again. Set a default browser in Windows settings if none opens.
Authentication failed or Error retrieving character list, try againWait a minute and try again. The Path of Exile website may be busy or down for maintenance.
Requests are being sent too fastWait for the seconds it shows, then try again.
Authenticated but no character list, only select your character's realm and a Start buttonLeave the box on PoE2 and click Start. Your league and character lists appear.
The advisor says the code is an empty buildThe code was made before importing your character. Do steps 6 to 9 in order, clicking Generate after the imports.
The Builds folder in Documents is emptyThat is normal. PoB only saves a file there when you click Save, and you don't need it: the advisor uses the code you copy in step 9. If you do save a build, you can also open that .xml file with the advisor's Open a saved file button.
Your character is not in the listChange the League box. Each league has its own list.
The account has no characters to import.You signed in with a different account from the one you play on. Click Logout from Path of Exile API and sign in with the right one.
The advisor says Could not decompress the codeOnly part of the code was pasted. Click Copy again and paste the whole thing.
The advisor says the code is from the first Path of ExileYou installed the wrong program. Use the PoE2 download in step 1.
